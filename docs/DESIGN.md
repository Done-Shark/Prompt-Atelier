# Prompt Atelier — 界面设计规范

> 视觉方向：**The Quiet Darkroom / 安静的暗房**。
> 界面几乎无彩，颜色属于内容：Prompt 的语法、Tag 的分类、两种格式的身份色。容器靠色阶和留白分层，不靠边框和阴影。

令牌唯一来源：`web/src/styles/tokens.css`。组件里禁止出现十六进制色值、魔法间距、硬编码圆角。

## 1. 信息架构

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶栏（52px）：页面名 · 全局搜索 · 主题                                │
├──────┬───────────────┬───────────────────────────────────────────────┤
│ 导航 │ 次级面板       │ 主内容                                         │
│ 64px │ 216px         │                                               │
│      │ 文件夹树       │ 提示词库：列表 + 详情（可切编辑）              │
│ 提示 │               │ NAI 图库：文件夹 + 网格 + 查看器               │
│ NAI  │               │ ComfyUI 图库：文件夹 + 网格 + 查看器           │
│ Comfy│               │ Tag 库：统计 + 表格                            │
│ Tag  │               │ 设置：左侧分类 + 右侧表单                      │
│ 设置 │               │                                               │
└──────┴───────────────┴───────────────────────────────────────────────┘
```

- **主导航**（64px 图标栏）：图标 + 10px 文字，当前项用 `--accent-wash` 圆角底 + `--accent` 前景。四项：提示词、NAI、ComfyUI、Tag 库；**设置固定在左下角**，不显示版本号（版本只在设置 → 关于里）。**「新建 Prompt」只出现在提示词模块的列表工具栏**，其他页面不显示（`Ctrl/Cmd + N` 仍然全局可用）。
- **次级面板**：提示词库与两个图片库都显示文件夹树（"全部 / 收藏 / 未归档"固定项 + 用户文件夹，可折叠子级）；Tag 库与设置页不显示次级面板。
- **提示词文件夹与图片文件夹同构**：都支持拖动排序 / 拖进子级 / 子文件夹 / 折叠 / 排序方式；行结构为「拖拽手柄 · 折叠箭头 · 示例图 22px · 名称 · 数量 · 更多」，示例图未设置时显示文件夹图标，点击即打开示例图选择器。选中文件夹后，Prompt 列表顶部出现分组头（44px 示例图 + 名称 + 条数 + 更换示例图）。
- **图片库是两个独立模块**：NAI 与 ComfyUI 各有自己的路由、文件夹树、筛选状态与空状态，不做顶部分区切换。
- **顶栏搜索**：宽度弹性，最大 520px。聚焦时展开为命令面板（`⌘K` / `Ctrl+K`），可搜 Prompt 标题与内容，回车打开第一条。

## 2. 提示词库

### 2.1 列表
- 默认「舒适列表」：每行 64–72px，包含：标题（`--fs-title`，单行省略）、正向 Prompt 摘要（等宽字体，2 行截断，语法着色）、标签（最多 3 个 + `+n`）、右侧元信息（目标色点 + 更新时间）。
- 顶部工具条：结果计数、排序（更新/创建/标题/使用次数）、视图切换（列表/紧凑）、目标筛选（全部 / NAI / ComfyUI 分段控件）。
- 选中行：`--selected` 底色 + 左侧 2px `--accent` 竖条；hover 用 `--hover`。
- 空状态：图标 + 一句说明 + 主操作（新建 Prompt / 导入）。搜索无结果时提供"清除筛选"。

### 2.2 详情 / 编辑
右侧 `--detail-w`（380px）常驻详情；点击"编辑"或双击行切换到编辑态（宽度 520px）。窄于 1100px 时详情改为覆盖式抽屉。

详情结构（自上而下）：
1. 标题 + 目标徽标 + 收藏按钮 + 更多菜单（复制、导出、删除）。
2. 正向 Prompt 卡片：等宽字体、语法着色、右上角"复制"；超过 8 行折叠，底部"展开"。
3. 负向 Prompt（可折叠，默认收起，显示首行）。
4. 参数：两列键值表（等宽数字），NAI 与 ComfyUI 各自字段。
5. 标签：可点击跳转筛选。
6. 元信息：创建/更新/使用次数/来源。
7. 底部操作条：编辑、从图片创建（若关联图片）、复制为 NAI / ComfyUI。

编辑态分三个页签：**内容 / 参数 / 笔记**。
- 内容：标题输入、目标分段控件（切换时提示参数将按新格式重置，需确认）。
  - **正面 Prompt 总览**：顶部一条只读高亮文本（语法着色），右侧「复制全部」。这是最终会输出到 NAI/ComfyUI 的完整文本。
  - **语义块列表**：按 `画师 → 人物/版权 → 外貌 → 服装 → 动作 → 表情 → 背景 → 构图 → 质量 → LoRA → 自定义 → 未分类` 排列，每块是一个可折叠卡片：
    - 块头：拖动手柄、块名（可改）、tag 计数、整块复制、折叠、更多（清空/删除）。
    - 块体：tag 芯片流式排列。单击芯片复制该 tag（保留权重语法），`×` 删除，右键可移动到其他块；底部输入框回车追加 tag。
    - 拖动块头调整顺序，顺序即输出顺序。
  - **快速导入**：粘贴一段原始 Prompt → 自动分词并分块；已有块可选择「追加」或「替换」。
  - **负面 Prompt**：默认折叠，显示首行摘要；展开后为等宽高亮文本 + 复制全部。
- 参数：按 target 渲染 `NaiParamsForm` / `ComfyParamsForm`；数值用带步进的紧凑输入；LoRA 列表支持增删行。
- 笔记：衬线字体多行输入。
- 页脚：取消 / 保存（`--ink` 实心按钮）。保存中禁用并显示 spinner，成功后关闭并提示。

### 2.3 语法着色
Prompt 文本按 token 渲染（纯前端，`lib/promptSyntax.ts`）：
- 权重包裹 `{}` / `[]` / `(x:1.2)`：`--syn-weight`（负权重 `--syn-weight-neg`）
- LoRA `<lora:name:0.8>`：`--syn-lora`
- 逗号与 `|`：`--syn-sep`
- 括号：`--syn-paren`
- 普通文本：`--syn-text`
着色只影响编辑态预览与详情展示；编辑输入框本身保持纯文本（用 `textarea` + 叠加高亮层实现，注意滚动同步）。

## 3. 图片库（NAI / ComfyUI 两个模块）

- 左侧上半：该目标的文件夹树（全部 / 未归档 + 用户文件夹，支持子级、新建、重命名、删除、折叠）；**固定手动顺序，只靠拖动调整**，不提供排序下拉。
- 左侧下半：相簿（收藏系统相簿 + 用户相簿），多对多集合，不影响文件夹归属；支持新建、重命名、删除。
- 拖动排序：整行都可拖（行内按钮不会打断）。文件夹与相簿都支持：落到某行上 30% → 插到前面，下 30% → 插到后面，中间 → 成为该文件夹的子级；拖到「未归档」或列表底部空白 → 回到根级末尾。拖动时目标行显示 2px 强调线（插入）或强调底色（成为子级），被拖行降到 45% 透明度，指针变成 grabbing。
- 实现用指针事件（`lib/useRowDrag.ts`）而不是 HTML5 拖拽：`dragover` 阶段 `dataTransfer` 被浏览器保护、且行内按钮会让 dragleave 反复触发，指针方案在鼠标/触控板上表现一致。
- 工具栏最左可隐藏/显示侧栏；状态按分区记忆。
- 顶部：模块标识（格式色点 + 名称）、搜索、数量、排序、网格密度、导入按钮。
- 导入自动归档到当前选中的文件夹；弹窗顶部提示"导入后归档到文件夹：xxx"。
- 拖拽：卡片可拖到左侧文件夹（目标行高亮 + 强调描边），也可拖到另一张卡片上调整顺序（左右半区决定插到前/后，显示 3px 强调竖线）。
- 多选：卡片左上角复选框（hover 或选中时显示）；`Ctrl/Cmd` 点选、`Shift` 连选、`Ctrl/Cmd + A` 全选、`Esc` 取消、`Delete` 删除。选中后顶部出现批量条（收藏 / 取消收藏 / 移动到… / 删除）。
- 外部拖入：从系统拖图片到文件夹行 → 导入并归档到该文件夹；拖到网格区域 → 导入到当前文件夹。拖入时显示「松手导入到「xxx」」遮罩，目标文件夹高亮。
- 文件夹数量显示含子文件夹的总数；移动、导入、删除后立即刷新。
- 右键菜单：打开、收藏、移动到文件夹…、从图片创建 Prompt、删除。
- 排序增加「自定义」；拖拽排序后自动切到该模式，并按分区记忆。
- 两个模块的文件夹完全隔离：NAI 与 ComfyUI 可以各有一个「场景」，互不冲突。
- 网格：等高行布局（目标行高 200px，最小 140px），间距 12px，图片圆角 `--r-sm`，`object-fit: cover`，加载前用 `--surface-2` 占位 + 淡入。
- 卡片 hover：轻微提亮 + 右上角操作（收藏、查看、转为 Prompt、删除）；不改变占位尺寸。
- 卡片底部信息仅在 hover 或聚焦时显示（文件名 + 模型），避免噪声。
- 点击打开查看器：全屏遮罩（`--scrim`），左侧大图（`--image-bg` 底），右侧 360px 元数据面板（正向/负向/参数/原始 JSON 折叠），底部上一张/下一张 + 键盘 `←/→/Esc`。
- 未识别元数据的图片：卡片角标"无参数"，查看器提示可手动"新建 Prompt"。
- 查看器正向 Prompt 下方按 **Tag 库分类**分组：人物 / 版权 / 画师 / 外貌 / 服装 / 动作 / 表情 / 背景 / 构图 / 质量 / 元信息 / 未分类。每个分组显示数量、可整组复制；每个 tag 显示英文 + 中文，单击复制，**双击 / F2 / 右键打开编辑浮层**（与 Tag 库同一份数据）。
- Tag 右键打开快捷编辑浮层（`components/TagEditPopover`，268px，跟随光标并收敛到视口内）：中文翻译（停顿 600ms 或失焦自动保存）、分类（下拉即时保存）、修正锁定状态切换。改动直接写回 Tag 库，`reviewed` 自动置 true，随后该 tag 会即时换组。
- 导入：弹窗内选择目标（自动识别 / 强制 NAI / 强制 ComfyUI）+ 目录路径（可保存到设置）+ 递归开关；显示扫描结果预览（文件名 + 识别结果 + 已存在标记），确认后导入并显示进度。

## 4. Tag 库

- 顶部统计：收录数、已翻译、待处理、已修正、内置词典条数。
- 工具条：搜索（tag / 翻译）、分类筛选、翻译状态分段（全部 / 待处理 / 已翻译 / 已修正）、排序。
- 表格列：选择框、Tag / 中文翻译（英文在上、中文在下；中文内联编辑，停顿 700ms 自动保存；英文点击复制）、分类（下拉）、来源（两行小字）、使用次数、修正锁。
- 表头吸顶；超过 200 条显示「加载更多」；批量操作支持设置分类、标记已修正。
- 人工改过翻译或分类 → 自动标记 `reviewed`，锁图标高亮；后续批量翻译 / Danbooru 同步跳过该条。
- 批量操作：翻译选中、设置分类、锁定 / 取消锁定、清空译文、复制选中；一次请求一个事务（`POST /api/tags/batch`）。
- 行内操作：点 Tag 复制、点译文直接改、分类下拉、锁图标、右侧「更多」菜单（复制 Tag / 复制译文 / 翻译这一条 / 清空译文 / 重命名或合并 / 锁定 / 在提示词库中查看）。
- 重命名弹窗：左边原 tag、右边目标，输入后自动 dryRun 预览「影响 X 条 Prompt、Y 张图片 / 分块与正负向替换数 / Tag 库动作」，确认后才执行。
- 查找替换弹窗：查找 + 替换（支持 `$1` 捕获组）、正则 / 区分大小写开关，列表逐条展示 `旧 → 新` 与使用次数，作用范围写明「当前筛选结果（N 条）」。
- 撤销：工具栏「撤销」按钮，禁用时提示「没有可撤销的操作」，可用时 tooltip 显示具体动作；撤销后 toast 回显动作名。
- 别名弹窗：搜索旧写法 / 规范 tag，每行 `旧 → 新`，行尾删除；点行可把列表筛到该 tag。
- 键盘流：译文输入框 `Enter` 保存并跳到下一条、`Tab` 保存并跳到分类、`Esc` 撤销。
- 使用次数可点，跳到提示词库并按该 tag 过滤；工具栏可按翻译来源（人工 / 内置词典 / OpenAI 兼容 / Gemini / 未翻译）筛选。
- 列表固定行高 52px，用虚拟滚动只渲染视口 + 8 行缓冲；表头与工具栏固定，滚动容器单独滚动；接近底部自动加载下一页（200/页）。
- 来源色：未翻译 / 内置词典 / 本地模型 / 人工，全部用文字而非彩色徽标，避免噪声。

## 5. 设置页

左侧分类导航（196px，`--pane` 底）+ 右侧内容（最大 760px）：
1. **外观**：主题（深色/浅色/跟随系统）、减少动效。
2. **提示词**：新建默认目标、复制附带参数、导入图片自动打标签。
3. **图片库**：NAI 与 ComfyUI 各一组扫描路径（可增删 / 浏览 / 直接扫描）。
4. **数据与备份**：数据目录（复制 / 打开）、整库备份（选择文件夹 / 从备份恢复）、Prompt 与 Tag 的 JSON 导入导出、危险操作（清空演示数据）。
5. **Tag 与翻译**：翻译方式（内置词典 / OpenAI 兼容 / Gemini）、接口地址 / 模型名称 / API Key（Gemini 有独立默认值与必填 Key 提示）、导入后自动翻译、允许 Danbooru 查询、批量处理入口。
5. **数据与备份**：数据目录、导出/导入 Prompt、导出/导入 Tag 库。
6. **关于**：版本、技术栈、参考项目。

## 6. 组件规范

| 组件 | 规范 |
| --- | --- |
| Button | 高度 32px（小号 26 / 大号 38）；圆角 `--r-ctl`；变体 `primary`（`--ink` 底）/ `secondary`（`--surface-2` 底 + 1px `--border`）/ `ghost`（透明，hover `--hover`）/ `danger`（`--danger-text` 文字，hover `--danger-wash`）；loading 时 spinner 替换图标、文字保留、宽度不变 |
| Input / Textarea | 高 32px，圆角 `--r-ctl`，底 `--surface-2`，1px `--border`，focus 时边框 `--accent` + 1px 外发光（用 box-shadow 0 0 0 2px `--accent-wash`）；placeholder 用 `--text-off` |
| SegmentedControl | 槽 `--surface-2`，滑块 `--surface`，选中文字 `--text`，未选中 `--text-3`；切换滑块 180ms `--ease-move` |
| Badge / Chip | 高 20–22px，`--r-sm`，NAI 用 `--nai-wash` + `--nai-text`，ComfyUI 用 `--comfy-wash` + `--comfy-text`，中性用 `--surface-3` |
| Card | 底 `--surface`，圆角 `--r-card`，1px `--border`，无阴影（静止）；hover 才提亮 |
| Modal | 最大宽 560px（编辑 720px），圆角 `--r-panel`，`--surface`，`--shadow-pop`，遮罩 `--scrim`；进入 180ms 淡入 + 4px 上移 |
| Toast | 底部居中，`--surface-3`，圆角 `--r-ctl`，4s 自动消失，最多同时 3 条 |
| EmptyState | 线性图标 28px（`--text-off`）+ 标题 + 说明 + 可选主操作，垂直居中 |
| Tooltip | 原生 `title` 仅作兜底；图标按钮必须有 `aria-label` |

**交互底线**
- 所有图标按钮有 `aria-label` 与 `title`。
- 焦点可见，Tab 顺序符合阅读顺序；Modal 打开时焦点进入第一个可操作元素，Esc 关闭。
- 危险操作（删除 Prompt / 文件夹 / 清空）必须二次确认，确认按钮用 `danger` 变体。
- 异步操作 > 300ms 显示 loading；失败用 Toast 展示服务端 `error.message`。
- 快捷键：`Ctrl/Cmd+K` 搜索、`Ctrl/Cmd+N` 新建、`Ctrl/Cmd+S` 保存编辑、`Esc` 关闭浮层、`/` 聚焦搜索。

## 7. 响应式

| 宽度 | 行为 |
| --- | --- |
| ≥1280px | 导航 + 次级面板 + 主内容 + 详情四区并存 |
| 1024–1279px | 隐藏次级面板（折叠为顶部下拉），详情保持 |
| <1024px | 单列：列表占满，详情为覆盖抽屉；导航收为底部或顶部图标条 |

本项目以桌面为主，移动端保证可用即可，不做功能裁剪。

## 8. 文案

- 界面语言中文，专有名词保留英文（Prompt、Tag、LoRA、NAI、ComfyUI、Seed、CFG）。
- 动词开头、不用"请"、不用感叹号。示例：`新建 Prompt`、`从图片创建`、`未识别到生成参数`、`已复制正向 Prompt`。
- 空状态不卖萌：`还没有 Prompt` / `把常用的提示词存进来，随时取用。`


## 9. RP 角色卡

- 入口：左侧导航「RP」，位于 Tag 库之后。
- 布局：三列——文件夹树（208px）+ 角色列表（280px）+ 详情。
- 文件夹树：全部 / 未归档 + 用户文件夹，支持子级、折叠、拖动排序与拖进子级；选中父文件夹时列表包含子级。
- 角色卡拖拽：按住列表行拖到文件夹行（或「未归档」）即可移动，目标行显示强调底色 + 内描边；拖拽结束后的那次 click 会被吞掉，不会误切换选中。
- 批量选择：列表头「批量选择」进入选择态，行左侧出现复选框、点击整行切换选中；批量条提供全选 / 移动到 / 删除 / 退出，选择态下禁用拖拽。
- 列表：每行「52px 原图缩略 · 名称 · 前 3 个标签」，支持搜索名称 / 标签 / 设定；顶部有导入与新建。
- 详情：132px 原图 + 名称 + 标签胶囊 + 来源信息（手动 / PNG / JSON、原始文件名、尺寸、体积）；
  下方依次是 RP 设定、简介、Prompt（等宽块 + 复制按钮）。
- 编辑弹窗：原图预览与更换、名称、标签（逗号分隔）、RP 设定、简介、Prompt。
- 图片一律保存原图，缩略图直接用原图缩放，不额外生成派生文件。
