# 项目简介 / Project Intro

## 中文

**一句话**：Prompt Atelier 是一个本地优先的 AI Prompt 与图片资产管理工具，同时适配 NovelAI 与 ComfyUI。

**简介**：

Prompt Atelier 把散落在聊天记录、输出目录和历史图片里的创作资产收进一个本地应用：Prompt 按语义分块管理，图片原图与生成参数一起入库，Tag 自动翻译分类并可自定义排序，SillyTavern 角色卡也能统一归档。数据全部保存在本机，支持整库备份与桌面安装包，不依赖云端账号。

**要点**：

- **Prompt 库**：语义分块、NAI / ComfyUI 双格式复制、从图片反解
- **图片库**：NAI / ComfyUI 双分区，原图按文件夹镜像存放，解析 NAI / ComfyUI / SwarmUI 元数据
- **Tag 库**：翻译、分类、自建分类与排序、批量修改、撤销
- **RP 角色卡**：PNG / JSON 导入、文件夹归档、批量操作
- **本地优先**：SQLite + 文件目录，整库备份，Electron 安装包

## English

**Tagline**: A local-first prompt and image asset manager for NovelAI and ComfyUI.

**Intro**:

Prompt Atelier brings scattered creative assets into one local app: prompts organized as semantic blocks, images stored together with their generation metadata, a tag library with translations and custom categories, and a home for SillyTavern character cards. Everything stays on your machine — SQLite plus plain image folders, full-library backup, and a desktop installer. No account, no cloud.

**Highlights**:

- **Prompt library**: semantic blocks, NAI / ComfyUI copy formats, image-to-prompt
- **Gallery**: separate NAI / ComfyUI libraries, folder-mirrored originals, NAI / ComfyUI / SwarmUI metadata
- **Tag library**: translations, categories, custom ordering, batch edits, undo
- **RP cards**: PNG / JSON import, folder organization, batch actions
- **Local-first**: SQLite + files, full backup, Electron installer
